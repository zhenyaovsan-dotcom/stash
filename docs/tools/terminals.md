# Trading terminals

Tools for discovering and trading Solana tokens.

## Axiom

**Type:** Trading terminal

A platform for token discovery, charting and trading.

- Website: [axiom.trade](https://axiom.trade/)
- Use it for: token discovery, monitoring and execution.
- Check fees and transaction settings before trading.

## How to evaluate a terminal

- Execution speed and transaction reliability
- Fee structure
- Token and wallet analytics
- Risk controls and slippage settings
- Security and wallet permissions
