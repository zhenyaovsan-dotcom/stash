# Tools directory

Tools are useful only when their output is understood in context. Treat decoded labels, wallet tags, risk scores and market-cap figures as signals to inspect—not as substitutes for evidence.

## Explorer and workflow

- [Read a transaction in Solscan](/tools/solscan) — inspect signature, instructions and balance changes.
- [Extensions & workflow](/tools/extensions) — a baseline for research and browser tooling.
- [Research terminals](/tools/terminals) — understand common terminal use cases and limitations.

## General rules

Prefer direct links to the exact transaction, mint, wallet or pool under review. Compare important claims with primary documentation. This starter site has no live API connection; no current prices, wallet alerts, or chain events are being simulated.
