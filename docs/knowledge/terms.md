# Trench glossary

Common terminology used in Solana memecoin trading.

| Term | Meaning |
|---|---|
| CA | Contract address; on Solana, usually the token's mint address. |
| Dev | Developer or deployer associated with a token launch. |
| LP | Liquidity pool, where assets are available for swaps. |
| Slippage | Difference between the expected and executed swap price. |
| Market cap | Estimated token valuation based on price and supply assumptions. |
| FDV | Fully diluted valuation, typically price multiplied by total supply. |
| Bundle | A group of transactions submitted together, often discussed in launch analysis. |
| Migration | Movement from a launch platform or bonding curve to another liquidity venue. |
| Holder | An address holding a token. One person may control multiple addresses. |
| Rug | A situation where insiders extract value and leave others with losses. |
| Sniper | A bot or trader attempting to buy immediately when trading becomes available. |
| Wallet cluster | Addresses suspected of being connected through funding or transaction patterns. |
| CT | Crypto Twitter, the crypto-focused community on X. |
| Jeet | Slang for a trader who sells quickly, often at the first price movement. |
| Pump | A rapid increase in token price. |
| Dump | A rapid sell-off that pushes the price down. |

*Terminology can vary by platform and community.*
